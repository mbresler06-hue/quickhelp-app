# QuickHelp

A modern service marketplace app for iOS and Android, built with Flutter.

## Run locally

1. Install Flutter SDK.
2. Run:
   ```bash
   flutter pub get
   flutter run
   ```

## Build Android APK

```bash
flutter build apk --release
```

## Build iOS app

```bash
flutter build ios
```

## Features included

- Modern home screen
- Service categories and cards
- Service detail screen
- Booking flow
- Profile screen
- Clean, premium visual design
